Desenvolvi um site a partir de uma proposta apresentada pelo professor, com o tema "Influencer de Plantas – Agência que transforma plantas em celebridades digitais".

O projeto conta com uma página inicial (index) e outras quatro páginas: Sobre Nós, Casting, Fale Conosco e Para Plantas, cada uma com conteúdos específicos relacionados à proposta da agência.

Também desenvolvi uma folha de estilos (style.css) para padronizar a identidade visual de todo o site.

Durante o desenvolvimento, utilizei HTML5, CSS3 e Bootstrap, aplicando as propriedades e os recursos solicitados pelo professor.
